# Legacy `/dossier/*` redirect stubs — temporary, safe to delete later

The tool description pages moved from `/dossier/*` to `/tool/*`. Google had already
indexed the old `/dossier/*` URLs, so after the rename they returned **404** and their
ranking signal was stranded.

The files in this folder are **not real pages** — each is a 13-line redirect stub
(instant `meta refresh` + `rel="canonical"` to the matching `/tool/*` URL, marked
`noindex`). They exist only so the old indexed URLs return a redirect instead of a 404,
which transfers their authority to the new pages.

They are generated by [`scripts/generate-redirects.mjs`](../../../scripts/generate-redirects.mjs)
(run via the `redirects` step in the root `build` script). Do not hand-edit; edit the
generator and the route list there instead.

## When can these be removed?

Delete this folder once **all** of the following are true (check via Google Search Console):

1. **Old URLs dropped from Google** — `site:dbastrosuite.com/dossier` returns nothing;
   `site:dbastrosuite.com/tool` shows the tool pages instead.
2. **GSC → Page indexing** lists the `/dossier/*` URLs as *"Page with redirect"* and the
   `/tool/*` URLs as *Indexed*.
3. **GSC → Performance** shows ~zero impressions/clicks for pages containing `/dossier`.
4. **No important external backlinks** still point at `/dossier/*` (the stub is what
   preserves their link value — repoint or wait until they're gone).

**Practical timeline:** usually 2–6 weeks for Google (slower for Bing) after deploy *and*
after requesting re-indexing of the `/tool/*` URLs. Safe default: keep ~3–6 months, then
verify the four conditions. They cost nothing, so there is no downside to keeping them.

## How to remove (when the time comes)

1. Delete this `hub/public/dossier/` folder.
2. Delete `scripts/generate-redirects.mjs` and remove the `redirects` step from the
   `build` script in the root `package.json`.
3. After deploy, `/dossier/*` returns 404 again — which is correct *at that point*,
   because Google no longer has those URLs.
